# 二、项目使用了什么技术

## 1. Vue 3

Vue 是一个用来写网页界面的 JavaScript 框架。

它可以让网页根据数据自动更新。

例如任务完成状态：

row.done = true

页面上的任务名字就会自动出现删除线，状态也会变成“已完成”。

不用 Vue 的话，你可能需要手动找到网页元素，再修改文字、颜色和样式。

Vue 会帮你自动完成这些事情。

———

## 2. Vite

Vite 是项目的开发工具。

它主要负责：

- 启动开发服务器
- 处理 Vue 文件
- 把项目打包
- 让修改代码后页面快速刷新

项目中的启动配置在：

D:/HUODUAN/my-vue-page/package.json

里面有三个主要命令：

"dev": "vite",
"build": "vite build",
"preview": "vite preview"

它们的作用分别是：

npm run dev

启动开发服务器，平时写代码时使用。

npm run build

把项目打包成上线文件。

npm run preview

预览打包后的项目。

在 Windows PowerShell 中，如果 npm 被脚本策略拦住，可以使用：

npm.cmd run dev
npm.cmd run build

## v-model 是什么

v-model 可以理解为“输入框和变量绑在一起”。

一开始：

const userName = ref('')

点击按钮时执行：

并且把名字放到地址参数中

## 3. v-show 和 v-if

页面中有两个按钮：

<button @click="toggleScoreBox2">上学期成绩</button>

点击第一个按钮：

也就是：

如果原来隐藏，就显示
如果原来显示，就隐藏

对应页面：

  <div v-show="show1">
    <p>绩点：{{score}}</p>
  </div>

v-show 的特点是：

元素一直存在，只是改变 display 样式

第二个按钮控制：

  <div v-if="show2">

v-if 的特点是：

条件不满足时，元素甚至不会创建

简单比较：

| 写法 | 含义 |
  |---|---|
| v-show | 东西还在，只是藏起来 |
| v-if | 条件不满足时，东西都不创建 |

## 6. 登录验证

## 3. 过滤任务

const filter = ref('all')

它表示当前看哪一类任务：

- all：全部
- active：未完成
- done：已完成

真正的过滤逻辑在：

const filteredList = computed(() => {
if (filter.value === 'active') {
return taskList.value.filter(item => !item.done)
}
if (filter.value === 'done') {
return taskList.value.filter(item => item.done)
}
return taskList.value
})

computed 就像“自动帮你算好的结果”。

意思是：

- 如果你点“未完成”，就只显示 done === false
- 如果你点“已完成”，就只显示 done === true
- 如果点“全部”，就全部显示

这很像你在书包里找东西：

- 只看没写完的作业

3. 用 filter 把这个任务从数组里去掉
4. 提示删除成功

filter(item => item.id !== id) 的意思就是：

只留下那些编号不等于当前 id 的任务

比如要删 id=3，那就把 3 以外的都留下。

}

意思是：

- 记住当前编辑的是谁
- 把旧名字放进输入框
- 打开弹窗

弹窗中的输入框：

  <el-input v-model="editName" placeholder="修改任务名称" />

点击确定执行：

const saveEdit = () => {

}
const target = taskList.value.find(item => item.id === editId.value)

}

ElMessage.success('修改成功')
}

就是：

1. 检查新名字是不是空的
2. 去数组里找到目标任务
3. 改它的名字
4. 关闭弹窗
5. 提示成功

这像你把“写作业”改成“写数学作业”。
